# Data and publication safety

This repository is an independent public portfolio project.

- All customers, transactions, values, outcomes, and identifiers are synthetic.
- Churn labels are derived from simulated future purchases; they are not copied from a company.
- No production query, table name, schema, server, credential, business threshold, or internal result is used.
- Generated data and fitted model files are excluded from version control.
- The committed reports can be reproduced from the documented random seed.

If you discover a credential or other sensitive value in the repository, do not open a public
issue. Contact the repository owner privately and revoke the affected secret immediately.
